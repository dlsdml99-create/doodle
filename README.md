## 소개

**그림이 친구가 돼요**
- 손가락으로 직접 그리거나, 종이에 그린 그림을 사진으로 찍어 올려요
- 밑그림 28가지(공룡 12종, 12간지 동물, 동화 나라)를 골라 색칠할 수 있어요
- 펜 10가지: 연필, 크레용, 마커, 붓, 스프레이, 무지개, 반짝이, 형광, 색칠통, 지우개
- 두 손가락 확대, 가로 화면 크게 그리기
- 그림 배경을 자동으로 오려내서 스티커 같은 친구로 만들어줘요

**같이 놀아요**
- 춤추기, 걷기, 점프, 말랑말랑, 인사하기, 빙글빙글, 쿨쿨 자기, 덜덜 떨기, 둥실 날기
- 친구를 톡 누르면 점프, 빈 곳을 누르면 그리로 걸어가요
- 최대 5명이 함께 놀고, **자동** 버튼을 누르면 알아서 놀고 말해요
- 커튼과 조명이 있는 무대, 들판, 바닷가, 눈 오는 날, 밤하늘, 우주, 도화지 배경

**연극을 해요**
- 누가 무슨 말을 할지 대본을 쓰면 순서대로 목소리로 읽어줘요
- 🎤 버튼으로 **내 목소리**를 녹음해서 캐릭터 목소리로 쓸 수 있어요

**꾸미고 남겨요**
- 왕관, 고깔모자, 리본, 꽃으로 친구를 꾸며요
- **녹화**로 무대를 영상으로 찍고, **찰칵**으로 사진을 찍어 갤러리 저장·카톡 보내기
- 만든 친구는 친구 상자에 자동 보관
